# Hestia — proposed UX specification (companion-led Island experience)

Updated October 15, 2026. **UX DESIGN APPROVED as part of the written spec; not implemented or device-verified.** Screen-level behavior, state table and exact acceptance criteria live in the [canonical written design](superpowers/specs/2026-10-15-island-first-companion-design.md), section 3–5.

**Primary visual order:** Companion face/illustration first, name and state second, session control third. Warm lavender/plum with cream backgrounds, platform text styles, soft motion and high contrast. VoiceOver reads the essential companion and session status; Reduce Motion and disabled animated images yield an expressive still. "Reduce character motion" applies to Hestia's own in-app playback and brief authored system effects on future available updates, never iOS-owned transitions. First encounter uses no account or permission wall.

**First-run screens:** Welcome/adopt or import → Companion Home (animated preview) → **Start Companion Mode** (user-owned until Stop) → optionally choose genuine task (e.g. "Creating together") and a proposed multi-hour Island window (example: 6 hours), with Lock Screen visibility preview → Live Activity window / fallback → window expired ("Companion Mode is still on; Restart Island session") or Stop Companion Mode. **Restart Island session is one tap inside Hestia**, using the last genuine task/duration with an adjacent Edit Session option; ActivityKit permission and error states remain explicit. The ~60-second target measures the **starter** path; imported GIF validation is separate. End window and Stop Companion Mode are distinct, accessible controls.

**Critical copy:** "Animated in Hestia." / "Companion Mode stays on until you stop it. To show your companion in Dynamic Island, start a real reading, creating, or study session. Each Island session can last up to eight hours, and iOS controls visibility." / "Your artwork stays on this phone, but it may be visible on your Lock Screen during a session." / "Island session ended. Your companion is still selected — tap Restart Island session to continue your activity." / "The Home Screen widget shows a still; iOS determines refresh timing." / On denial: "Live Activities are turned off. You can enable them in Settings, or continue here."

**Presentation truth:** Compact Island is tiny, minimal even smaller, expanded/Lock Screen show more; no visual guarantee of Island residency. Short expression effects accompany *meaningful app-executed content updates* and can be suppressed by the OS. Starting an Activity or reaching a timer deadline does not guarantee an animated expression. Rich in-app GIF playback remains separate. Date-driven countdown reaching zero cannot automatically end ActivityKit or change ContentState; present "Focus ends at [time]" rather than a misleading static "Focusing" label, then reconcile next time the app executes.

**Import recovery:** Validate Photos/Files selections, preserve GIF data when available and show a non-destructive error with "Choose another image." Keep imported art local. Imported GIF animates in Hestia but is shown as a chosen still on system surfaces; Hestia does not synthesize blink/cheer poses for arbitrary art. UI must also work with original starter art when an asset is unavailable. If ActivityKit is switched off, point to Settings; if only Island hardware is missing, use the Lock Screen; if ActivityKit returns another error, give a retry option without implying Settings can solve every failure.
