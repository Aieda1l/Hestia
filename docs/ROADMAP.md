# Hestia — approved design, proposed delivery roadmap

Updated 2026-10-15. **Implementation roadmap is a proposal pending separate plan approval.**

The [approved Island-first design](superpowers/specs/2026-10-15-island-first-companion-design.md) is one journey with two separately reviewed engineering increments.

1. **Island Companion Core.** Source recheck or expressly authorized minimal native scaffold → original starter + persistent Companion Mode → legitimate bounded study/reading/creative task → ActivityKit compact/minimal/expanded Island and Lock Screen → stop/recovery/denied/non-Island states → in-app one-tap new activity using saved task/duration → Mac and device gates. See [core plan](superpowers/plans/2026-10-15-island-companion-core.md).
2. **Custom Art + Home Screen Widget.** Secure PNG/JPEG/GIF import and in-app GIF playback → static representative poster and App Group session snapshot → secondary small/medium snapshot widget → privacy, memory, accessibility and signed device checks. See [custom art plan](superpowers/plans/2026-10-15-companion-art-and-widget.md).

**Sequence:** The second increment depends on the core's verified storage and ActivityKit interfaces. Avoid concurrent changes to project configuration, entitlements, shared models and widget extension. Original source restoration must be checked before execution.

**Deferred, not included in these plans:** autonomous Island idle loops, opt-in expiry notifications, Shortcuts/Control Center initiation, cloud/accounts, social, AI generation, complex sprite editing, subscriptions and indefinite Island residency.
